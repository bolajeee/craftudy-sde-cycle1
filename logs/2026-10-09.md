```js
const taskIndex = tasks.findIndex((task) => task.id === id);

if (taskIndex === -1) {
  return res.status(404).json({ error: "Task not found" });
}

tasks.splice(taskIndex, 1);

return res.status(204).send();
```

**Key learning:** `findIndex()` locates an item in an array, while `splice()` removes it. A `204 No Content` response indicates success without returning a response body.
