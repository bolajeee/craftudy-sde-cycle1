## DSA
- Problem: Two sums (Given a set of numbers, We need to find two different elements whose values add up to 9 and the problem wants their indices, not the values.)
 
 From Two sums DSA, i practiced algorithmic planning 

    i.e Start with the first number.
         Compare it with every number after it.
            If their sum equals the target:
                return their indices.
            If none work:
                move to the next number.


 Solution (Brute Force Method):



 function twoSum(nums, target) {
    const map = new Map();

    for (let i = 0; i < nums.length; i++) {
        const needed = target - nums[i];

        if (map.has(needed)) {
            return [map.get(needed), i];
        }

        map.set(nums[i], i);
    }
}
