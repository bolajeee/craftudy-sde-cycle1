**Two Sum — hash map approach**
```js
const current = nums[i];
const needed = target - current;

if (seen.has(needed)) {
  return [seen.get(needed), i];
}

seen.set(current, i);
```

**Group Anagrams — grouping with a Map**
```js
const key = words[i].split("").sort().join("");

if (!groups.has(key)) {
  groups.set(key, []);
}

groups.get(key).push(words[i]);
```
