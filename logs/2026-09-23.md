## DSA — Valid Anagram

## Problem

Determine whether two strings contain the same characters with the same frequencies, regardless of their order.

Examples:

```text
"listen"  → "silent"   true
"hello"   → "world"    false
"anagram" → "nagaram"  true
```

## Algorithm

1. If the strings have different lengths, return `false`.
2. Create a `Map` to store character frequencies.
3. Iterate through the first string and increment each character's count.
4. Iterate through the second string and decrement each character's count.
5. If a required character does not exist, return `false`.
6. Check that all remaining counts are zero.
7. Return `true`.

## Key concept

```text
	Set → stores unique values / checks existence

	Map → stores key → value relationships
```

For Valid Anagram, we need:

```text
	character → frequency
```

so a `Map` is appropriate.

## Complexity

* **Time:** `O(n)`
* **Space:** `O(k)` where `k` is the number of distinct characters.

## Main takeaway

When **order does not matter but frequency does**, a frequency map is a useful pattern to consider.

## Codebase

function isAnagram(s, t) {
  if (s.length !== t.length) {
    return false;
  }

  const counts = new Map();

  for (const char of s) {
    counts.set(char, (counts.get(char) || 0) + 1);
  }

  for (const char of t) {
    if (!counts.has(char)) {
      return false;
    }

    counts.set(char, counts.get(char) - 1);
  }

  for (const count of counts.values()) {
    if (count !== 0) {
      return false;
    }
  }

  return true;
}

console.log(isAnagram("listen", "silent")); // true
console.log(isAnagram("hello", "world"));   // false
console.log(isAnagram("anagram", "nagaram")); // true
