## DSA

* **Problem:** Contains Duplicate — Given an array of numbers, determine whether any value appears more than once.

**Algorithmic Breakdown**

1. Create an empty Set.
2. Loop through each value in the array.
3. Check if the current value already exists in the Set.
4. If it exists, return `true`.
5. If it does not exist, add the value to the Set.
6. If the loop finishes without finding a duplicate, return `false`.

**Code Solution**

let nums = [1, 2, 3, 4, 5, 6, 7, 5, 3];

function containsDuplicate(nums) {
    let seen = new Set();

    for (let i = 0; i < nums.length; i++) {
        if (seen.has(nums[i])) {
            return true;
        }

        seen.add(nums[i]);
    }

    return false;
}
