**DSA**

Problem: Best Time to Buy and Sell Stock

Given an array of stock prices where each value represents the price on a particular day, find the maximum profit possible by buying on one day and selling on a later day.

Example:

prices = [7, 1, 5, 3, 6, 4]

The maximum profit is:

6 - 1 = 5

Algorithmic planning

Instead of comparing every possible pair of buying and selling days, I can go through the array once.

While moving from left to right, I only need to remember:

1. The cheapest price seen so far.
2. The maximum profit found so far.

For every price:

If the price is cheaper than the current minimum:
    update the minimum price.

Otherwise:
    calculate the profit if I bought at the minimum
    and sold at the current price.

    If this profit is greater than the current maximum:
        update the maximum profit.

Important learning

I initially thought that because the solution goes through the array once, it should use a Map or Set. I learned that one-pass does not mean Map or Set.

Contains Duplicate uses a Set because the problem requires remembering whether a value has already appeared.

Best Time to Buy and Sell Stock only requires remembering two pieces of information:

minPrice
maxProfit

**JavaScript solution**

function maxProfit(prices) {
    let minPrice = prices[0];
    let maxProfit = 0;

    for (const price of prices) {
        if (price < minPrice) {
            minPrice = price;
        } else {
            const profit = price - minPrice;

            if (profit > maxProfit) {
                maxProfit = profit;
            }
        }
    }

    return maxProfit;
}

Complexity
Time: O(n) — the array is traversed once.
Space: O(1) — only minPrice, maxProfit, and profit are stored; no additional data structure grows with the input.
