## What I worked on

* Created a dedicated `validateTask` middleware instead of keeping validation logic inside the route.
* Learned how Express middleware uses `next()` to pass control to the next handler.
* Used Zod's `safeParse()` to validate `request.body`.
* Stored validated data in `request.task` rather than continuing to use the untrusted request body.
* Debugged a middleware import/export issue caused by the difference between:

  * `module.exports = validateTask`
  * `const validateTask = require(...)`
* Removed the old route-level validation logic after moving validation into middleware.

const result = createTaskSchema.safeParse(request.body);

if (result.success == false) {
    response.statusCode = 400;
    response.end("Invalid task format, unable to create task");
    return;
}

request.task = result.data;

next();
